# CNC 设备 TikTok B2B 获客项目记录

## 项目背景

- 产品：CNC 加工设备及行业应用方案。
- 目标区域：东南亚、中东。
- 目标客户：采购设备用于生产的企业，以及设备经销商。
- 业务问题：如何将企业现有宣传资料转化为能吸引目标采购商的视频内容，并建立询盘筛选流程。

## AI 使用与贡献边界

项目负责人提供业务背景、公司及品牌信息、目标区域和客户类型，并补充当前产品宣传资料，纠正旧网页信息不适用于当前产品的问题。

本仓库中的资料提取、图片文字识别、分析框架、脚本与文档整理由 Codex 辅助完成。它体现项目负责人组织业务输入、使用 AI 推进分析和形成可审阅产出的过程。技术配置、海外交付及售后承诺仍需企业业务或技术人员确认。
